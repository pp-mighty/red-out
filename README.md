# RED OUT オンライン（非公式・友だち用）

スマホのブラウザで、友だちと2〜8人で RED OUT を対戦できるページです。
ゲーム画面は GitHub Pages、プレイヤー間の同期は Firebase Realtime Database（無料プラン）で動きます。
遊ぶ人はアカウント不要で、招待リンクを開くだけで参加できます。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 画面と進行 |
| `game.js` | ルール（勝敗判定・脱落・再戦） |
| `store.js` | Firebase とテストモードの切り替え |
| `firebase-config.js` | **ここに Firebase の設定を貼る** |
| `database.rules.json` | Firebase に貼るセキュリティルール |
| `manifest.webmanifest` / `icon*` | ホーム画面に追加したときのアイコン |

---

## 1. まずパソコンで試す（任意・1分）

`index.html` を Chrome で開き、同じページをもう1つのタブでも開きます。
片方で「部屋を作る」、もう片方で部屋コードを入れて「参加する」と、タブ同士で対戦できます。
（Firebase を設定するまでは、このテストモードで動きます）

## 2. Firebase を準備する（10分ほど・無料）

1. [Firebase コンソール](https://console.firebase.google.com/) に Google アカウントでログインし、「プロジェクトを作成」。名前は `redout-online` など自由です。Google アナリティクスはオフで構いません。
2. 左のメニューの「構築」から「Realtime Database」を開き、「データベースを作成」。
   - ロケーションは日本から近い **シンガポール（asia-southeast1）** がおすすめです。
   - セキュリティルールは「ロックモードで開始」を選びます。
3. Realtime Database の「ルール」タブを開き、`database.rules.json` の中身をまるごと貼り付けて「公開」。
4. 左上の歯車から「プロジェクトの設定」を開き、「マイアプリ」でウェブ（`</>` のアイコン）を選んでアプリを登録します（Firebase Hosting の設定は不要）。
5. 表示された `firebaseConfig` の各値を、`firebase-config.js` の同じ名前の項目にコピーします。
   - `databaseURL` が表示されない場合は、Realtime Database の画面上部にある `https://〜.firebasedatabase.app` の URL を貼ってください。

> `firebase-config.js` の値は、ページを開いた人なら見られる前提のもので、パスワードではありません。
> 読み書きできる範囲は手順3のルールで「部屋コード付きの部屋データだけ」に絞っています。

## 3. GitHub Pages で公開する（5分ほど）

1. GitHub で新しいリポジトリを **Public** で作ります（例：`redout`）。
2. リポジトリの画面で「Add file」→「Upload files」を選び、このフォルダのファイルを全部ドラッグして「Commit changes」。
3. 「Settings」→「Pages」で、Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にして「Save」。
4. 1〜2分待つと `https://（GitHubのユーザー名）.github.io/redout/` で開けるようになります。

設定を直したいときは、GitHub 上で `firebase-config.js` を開いて鉛筆アイコンから編集すれば反映されます。

## 遊び方

1. スマホで公開した URL を開き、名前と対戦人数を選んで「部屋を作る」。
2. 「招待リンクを送る」で LINE などに送ります。友だちはリンクを開いて名前を入れるだけで参加できます。
3. 人数がそろったら、ホスト（部屋を作った人）が「対戦を始める」。
4. 決着したら「次の試合へ」で、同じメンバーですぐ次の試合が始まります。勝ち数は部屋にいる間ずっと数えられます。
5. 人数を変えたいときや、新しい人を入れたいときは、ホストが「ロビーに戻って人数を変える」。

**アプリのように使う：** iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」で、全画面で開けるようになります。

### ルール（3人以上に拡張済み）

- 全員が同じ5枚（黒・白・黒ドクロ・白ドクロ・赤ドクロ）を持って始めます。
- 1枚ずつ伏せて出し、全員そろったら一斉に公開します。
- 赤ドクロは黒ドクロと白ドクロに勝ち、黒ドクロは黒に、白ドクロは白に勝ちます。それ以外はすべて引き分け。
- 誰か1人にでも負けた人は脱落。出した札は勝っても引き分けでも捨て札です。
- 最後の1人になった人の勝ち。2人対戦なら原作どおりの動きになります。
- 生き残った全員が5枚を使い切ったら、手札を戻して再戦します。

## しくみのメモ

- **のぞき見対策：** 札を伏せた時点では、選んだ札そのものではなく「札＋ランダムな文字列」の SHA-256 ハッシュだけを送ります。全員がそろってから中身を公開し、各端末がハッシュと照合します。開発者ツールで通信を見ても、公開前に相手の札は分かりません。
- **切断したとき：** 他の人の画面に「切断中」と表示されます。同じスマホで開き直せば同じ席に戻れます。戻れない人は、ホストが席の「脱落扱い」で外せます。
- **画面のスリープ：** 部屋にいる間は、対応している端末なら画面が自動で消えないようにしています。
- **データ：** 部屋のデータは Firebase に残ります。気になるときは Realtime Database の画面で `rooms` を削除すれば消えます。最後の1人が退出した部屋は自動で消えます。
- **無料枠：** 無料プランの同時接続数の上限は100です。友だち同士で遊ぶ分には十分です。

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| 「Firebase に接続できませんでした」と出る | `firebase-config.js` の値（特に `apiKey` と `databaseURL`）が正しく貼れているか |
| 部屋を作るとエラーになる | 手順2-3のルールを「公開」したか |
| 画面上部に「テストモード」と出る | `firebase-config.js` が空のまま。GitHub 上のファイルが更新されているか |
| 参加できない | 対戦中の部屋には途中から入れません。ホストにロビーに戻してもらうか、人数を増やしてもらってください |
