# RED OUT オンライン（非公式・友だち用）

スマホのブラウザで、友だちと2人で RED OUT を対戦できるページです。観戦は何人でもできます。
ゲーム画面は GitHub Pages、プレイヤー間の同期は Firebase Realtime Database（無料プラン）で動きます。
遊ぶ人はアカウント不要で、招待リンクを開くだけで参加できます。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 画面と進行 |
| `game.js` | ルール（手札・勝敗判定・再戦・色の割り当て） |
| `store.js` | Firebase とテストモードの切り替え |
| `firebase-config.js` | **ここに Firebase の設定を貼る** |
| `database.rules.json` | Firebase に貼るセキュリティルール |
| `manifest.webmanifest` / `icon*` | ホーム画面に追加したときのアイコン |

## 1. まずパソコンで試す（任意・1分）

`index.html` を Chrome で開き、同じページをもう1つのタブでも開きます。
片方で「部屋を作る」、もう片方で部屋コードを入れて「参加する」と、タブ同士で対戦できます。
（Firebase を設定するまでは、このテストモードで動きます）

## 2. Firebase を準備する（10分ほど・無料）

1. [Firebase コンソール](https://console.firebase.google.com/) に Google アカウントでログインし、「プロジェクトを作成」。名前は `redout-online` など自由です。Google アナリティクスはオフで構いません。
2. 左のメニューの「構築」から「Realtime Database」を開き、「データベースを作成」。
   - ロケーションは日本から近い **シンガポール（asia-southeast1）** がおすすめです。
   - セキュリティルールは「ロックモードで開始」を選びます。
3. Realtime Database の「ルール」タブを開き、`database.rules.json` の中身をまるごと貼り付けて「公開」。
4. 左上の歯車から「プロジェクトの設定」を開き、「マイアプリ」でウェブ（`</>` のアイコン）を選んでアプリを登録します（Firebase Hosting の設定は不要）。
5. 表示された `firebaseConfig` の各値を、`firebase-config.js` の同じ名前の項目にコピーします。
   - `databaseURL` が表示されない場合は、Realtime Database の画面上部にある `https://〜.firebasedatabase.app` の URL を貼ってください。

> `firebase-config.js` の値は、ページを開いた人なら見られる前提のもので、パスワードではありません。
> 読み書きできる範囲は手順3のルールで「部屋コード付きの部屋データだけ」に絞っています。

## 3. GitHub Pages で公開する（5分ほど）

1. GitHub で新しいリポジトリを **Public** で作ります（例：`redout`）。
2. リポジトリの画面で「uploading an existing file」（空のリポジトリの場合）または「Add file」→「Upload files」を選びます。
   zip を展開した `redout` フォルダを開き、**中のファイル13個をまとめて選んで**ドラッグします（zip ファイルそのものや、`redout` フォルダごとは入れません）。
   最後に画面下の緑の「Commit changes」ボタンを押すまでがアップロードです。
3. リポジトリのトップに `index.html` などが並んでいることを確認してから、「Settings」→「Pages」で、Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にして「Save」。
   - Branch に「None」しか出ないときは、まだファイルがコミットされていない（リポジトリが空の）状態です。手順2の「Commit changes」まで済ませてから、このページを開き直してください。
4. 1〜2分待つと `https://（GitHubのユーザー名）.github.io/redout/` で開けるようになります。

設定を直したいときは、GitHub 上で `firebase-config.js` を開いて鉛筆アイコンから編集すれば反映されます。

**更新するとき：** 新しいファイルをもらったら、`index.html` と `version.json` もいっしょに上書きアップロードしてください。ダウンロードフォルダに同じ名前の古いファイルが残っていると、名前の後ろに `_1` が付いて別のファイルとして上がってしまうので、新しいフォルダに展開してからアップロードするのが確実です。遊んでいる人のスマホも、対戦中でなければ自動で新しい版に切り替わります（対戦中なら画面上に「新しいバージョンがあります」と出ます）。

## 遊び方

1. スマホで公開した URL を開き、名前を入れて「部屋を作る」。
2. 「招待リンクを送る」で LINE などに送ります。友だちはリンクを開いて名前を入れるだけで参加できます。
3. 2人そろったら、ホスト（部屋を作った人）が「対戦を始める」。
4. 決着したら「次の試合へ」で、すぐ次の試合が始まります。勝ち数は部屋にいる間ずっと数えられます。

### 観戦する

- 招待リンクを開いて「観戦する」を選ぶと観戦できます。名前は空欄でも大丈夫です。対戦中の部屋は「観戦する」だけが表示されます。
- 観戦者にも、伏せた札は公開まで見えません（プレイヤーと同じ情報だけが見えます）。途中から観戦しても、その時点の残り札と試合の記録が見られます。
- 観戦者は、画面下の応援スタンプ（👏 🔥 😱 😢 🎉）を押せます。全員の画面の端に、押した人の名前つきで浮かび上がります。
- 試合が終わったら、観戦者は「次の試合に参加する」を押します。席は2つなので、対戦していた人が「次は観戦にまわる」を押すと交代します（参加を待っている人がいると、対戦者の結果画面にお知らせが出ます）。待っている人が複数いれば、申し込んだ順に入ります。
- ロビーで空席があるときは、観戦者は「対戦に参加する」ですぐ席に着けます。

**アプリのように使う：** iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」で、全画面で開けるようになります。

### ルール

- 2人で対戦します。1人が黒、もう1人が白の札を3枚ずつ持ちます。
  - 黒の手札：赤ドクロ・黒ドクロ・黒無印
  - 白の手札：赤ドクロ・白ドクロ・白無印
- 強さは三すくみです（色は関係ありません）。
  - 赤ドクロは、ドクロ（黒ドクロ・白ドクロ）に勝つ
  - ドクロは、無印（黒無印・白無印）に勝つ
  - 無印は、赤ドクロに勝つ
- 同じ種類どうし（赤ドクロ同士、ドクロ同士、無印同士）は引き分けです。
- 1枚ずつ伏せて出し、2人そろったら一斉に公開します。勝った人がその試合の勝ちです。
- 引き分けなら、出した札は捨て札になって次の勝負へ進みます。3回とも引き分けで札が尽きたら、手札を戻して再戦します。
- 第1試合は先に部屋にいた人が黒です。同じ2人で続けるときは、試合ごとに黒と白が入れ替わります。

## しくみのメモ

- **のぞき見対策：** 札を伏せた時点では、選んだ札そのものではなく「札＋ランダムな文字列」の SHA-256 ハッシュだけを送ります。2人がそろってから中身を公開し、各端末がハッシュと照合します。開発者ツールで通信を見ても、公開前に相手の札は分かりません。
- **切断したとき：** 他の人の画面に「切断中」と表示されます。同じスマホで開き直せば同じ席に戻れます。戻れない人は、ホストが席の「負け扱いにする」で決着させられます。
- **画面のスリープ：** 部屋にいる間は、対応している端末なら画面が自動で消えないようにしています。
- **データ：** 部屋のデータは Firebase に残ります。気になるときは Realtime Database の画面で `rooms` を削除すれば消えます。最後の1人が退出した部屋は自動で消えます。
- **無料枠：** 無料プランの同時接続数の上限は100です。友だち同士で遊ぶ分には十分です。

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| 「Firebase に接続できませんでした」と出る | `firebase-config.js` の値（特に `apiKey` と `databaseURL`）が正しく貼れているか |
| 部屋を作るとエラーになる | 手順2-3のルールを「公開」したか |
| 画面上部に「テストモード」と出る | `firebase-config.js` が空のまま。GitHub 上のファイルが更新されているか |
| 参加できない | 対戦中や満員の部屋には「観戦する」で入り、試合が終わったら「次の試合に参加する」を押してください |
